# React Best Practices - context index

This directory is bundled skill source, not the Svelte application rule set.

- Read `SKILL.md` first, and only when working on React or Next.js code.
- Load individual files from `rules/` only for the current performance concern.
- Do not load the entire rules collection into context.
- Do not apply React-specific guidance to the Svelte application outside this plugin directory.
- The project root `AGENTS.md` and `~/codex-workspace/AGENTS.md` remain the governing instructions.
